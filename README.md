# Print Queue Simulator

A simple menu-driven Print Queue Simulator developed using C.

The project demonstrates how a printer manages multiple document requests using the Queue data structure.

## Features
- Add print jobs (Enqueue)
- Process print jobs (Dequeue)
- Display pending documents
- View the next document (Peek)
- Check empty and full queue conditions

## Concepts Used
- C Programming
- Arrays
- Queue Data Structure
- FIFO Principle
- Functions
- Structures of operations and menu-driven programming

## Queue Principle

FIFO (First In, First Out).

The first document added to the queue is the first document processed.

## Queue Operations
| Operation | Description |
|---|---|
| Enqueue | Add a document |
| Dequeue | Process a document |
| Peek | View the next document |
| Display | Show pending documents |

## Limitation
This version uses a linear queue implemented with a fixed-size array.
